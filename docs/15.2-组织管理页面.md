# 15.2｜组织管理页面

## 一、本节目标

本节把组织管理相关的 `curl` 操作替换为可视化页面，同时调整后台整体视觉风格。

完成后可以：

1. 从左侧菜单切换“工作台”和“组织管理”；
2. 查询真实组织列表；
3. 按组织编码或名称搜索；
4. 打开右侧表单创建组织；
5. 在浏览器端检查必填项和最大长度；
6. 显示创建成功、接口错误和加载失败状态。

## 二、视觉调整

后台采用接近 Codex、Gemini 等工具产品的极简管理界面：

```text
左侧：固定工具导航
顶部：当前页面标题和简短说明
主体：数据卡片、状态面板、表格
操作：低饱和绿色作为主要按钮
反馈：浅绿表示成功，浅红表示错误
```

产品页面不显示章节编号、学习进度或实验说明。以下内容只存在于 `docs/` 笔记：

```text
15.1、15.2 等章节编号
本节目标
实验步骤
下一节预告
```

- 组织和用户数量；
- Java BFF 与 Python LINK 服务状态；
- 常用管理入口；

统一视觉变量定义在：

## 三、新增和修改的文件

### 1. `src/views/OrganizationView.vue`

组织管理页面，负责：

- 加载组织列表；
- 本地搜索；
- 表单显示和关闭；
- 浏览器端基础校验；
- 调用 Java BFF 创建组织；
- 反馈成功和错误信息。

### 2. `src/api/platform.ts`

新增：

```ts
createOrganization({
  organizationCode,
  organizationName,
})
```

请求：

```text
POST /api/v1/platform/organizations
Content-Type: application/json
```

同时增强了错误解析。Java 返回非 2xx 状态时，前端会尝试读取：

```text
detail
message
error
```

如果没有可读的 JSON 错误正文，才显示 HTTP 状态码。

### 3. `src/App.vue`

保存当前页面状态：

```ts
type PageKey = 'dashboard' | 'organizations'
```

当前还没有引入 Vue Router，因为只有两个学习页面。等页面数量增加后再专门学习路由，
可以避免一次引入过多概念。

### 4. `src/layouts/AdminLayout.vue`

菜单不再是纯静态展示：


布局通过 `navigate` 事件告诉 `App.vue` 切换页面。

### 5. `src/style.css`

重做后台整体视觉，并新增：

- 统一颜色变量；
- 浅色侧栏；
- 工作台卡片层次；
- 组织数据表格；
- 搜索框；
- 创建组织抽屉；
- 成功和错误提示；

### 6. `src/components/UiIcon.vue`

统一管理后台中的线性 SVG 图标。侧栏、数据卡片、搜索框和按钮都复用该组件，
不再用“组、人、角、权”等文字代替图标。

## 四、页面数据流程

### 查询流程

```text
打开组织管理页面
        ↓
onMounted(loadOrganizations)
        ↓
GET /api/v1/platform/organizations
        ↓
Java BFF 查询 platform_organization
        ↓
Vue 显示表格
```

### 创建流程

```text
点击“新增组织”
        ↓
填写编码和名称
        ↓
前端检查必填与长度
        ↓
POST /api/v1/platform/organizations
        ↓
Java 再次执行后端校验和编码重复检查
        ↓
成功：加入列表并显示成功提示
失败：保留表单并显示错误
```

前端校验是为了尽早提醒用户，不能替代 Java 后端校验。任何调用方都可能绕过浏览器，
所以真正的业务规则仍然必须在 Java 中执行。

## 六、实验步骤

### 实验一：查询组织

1. 点击左侧“组织管理”；
2. 页面显示现有组织；
3. 应当能看到：

```text
SAND_DUNE_OS
沙丘 OS
启用
```

### 实验二：搜索组织

在搜索框输入：

```text
SAND
```

现有组织应保留。输入不存在的内容时，显示“没有匹配的组织”。

搜索只在已经加载到浏览器的数据中执行，本节还没有实现后端分页和后端搜索。

### 实验三：浏览器端校验

1. 点击“新增组织”；
2. 不填写内容；
3. 点击“确认创建”；
4. 页面应提示“请输入组织编码”。

### 实验四：重复编码

输入：

```text
组织编码：SAND_DUNE_OS
组织名称：重复组织实验
```

Java BFF 应返回冲突错误，数据库不会新增记录。

### 实验五：创建新组织

建议使用明确的学习数据，例如：

```text
组织编码：SAND_DUNE_EAST
组织名称：沙丘华东学习中心
```

成功后：

- 抽屉关闭；
- 页面显示成功提示；
- 新组织出现在列表中；
- 刷新浏览器后记录仍然存在。
